# autoMod

> **Note: This project is no longer maintained.**
>
> It was last updated in **January 2023** and the repository was archived on **October 31, 2025**. The information below is for historical purposes. Links and discord functionality may no longer work.

-----

autoMod **was** a moderation bot for Discord that **was** designed to make managing a server easy and efficient. The bot **was** equipped with powerful features that **allowed** for automatic deletion of messages containing specific keywords or phrases, banning or kicking of users who violated the server's rules, and logging of all moderated actions for easy reference and accountability.

The bot **could** be easily installed by inviting it to a server via the [provided link](https://discord.com/api/oauth2/authorize?client_id=782985846474932315&permissions=8&scope=applications.commands%20bot) and **configured** using the available slash commands. Additionally, it **had** a **[support server](https://discord.gg/2je9aJynqt)** and an **[open-source GitHub repository](https://github.com/ThatsLiamS/autoMod)** where users **could** report issues or contribute to its development. Overall, autoMod **was** a reliable and user-friendly solution for managing a Discord server effectively.

## Support

#### General Support

If users **were** ever unsure about autoMod or **had** any questions, they **were encouraged** to join our [Discord Support Server](https://discord.gg/2je9aJynqt) where we **were** happy to answer any concerns.

#### Reporting Issues

We previously **supported** two separate ways to report any issues and bugs with autoMod.

1. The first **was** the **/report** command; filling in the modal with as much information as possible **would** then promptly alert the developers.

2. The second **was** to open an [issue](https://github.com/ThatsLiamS/autoMod/issues) on the GitHub repository. Upon opening a new GitHub Issue, users **filled** out all the relevant fields and **submitted** the report.
